# 数据契约

元件数量与 BOM 单板数量均为非负整数，出入库必须为正整数；编号唯一。BOM 的已确认映射保存元件 ID，不用名称猜测替代料。BOM 每行总需求为 `ceil(单板数量 × 板数 × (1 + 备料百分比 / 100))`，相同元件跨行累计占用。

匹配优先内部编号、立创编号，然后精确型号与封装；同名多候选、封装冲突和仅参数匹配需人工确认。领料在单个事务中重算实时库存；默认整单足量才出库，可明确选择仅领现有数量；每张 BOM 只允许领料一次。

所有接口返回 JSON，失败为 `{error: 中文消息}`。表格上传为 JSON `{name, data: base64}` 或 `{text}`，返回列与原始行，由前端映射后提交；单文件最大 10 MiB，最大 5000 行。
